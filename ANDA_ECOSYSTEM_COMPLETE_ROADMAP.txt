Platform 1: ANDA DIRECTORY
=====================================================
SCOPE: Resource discovery platform
TIMELINE: 8-10 weeks (start: Week 13 of project)
STATUS: Specifications ready

WHAT IT DOES:
- Searchable database of 1000+ practitioners (Doctors, therapists, educators)
- Location-based search (by country, city)
- Specialization filtering (ADHD, Autism, Dyslexia, Dyspraxia)
- Practitioner verification system (blue badges)
- Community reviews & ratings
- Appointment booking integration
- Support group directory
- Organization listings (NGOs, schools, advocacy groups)

HOW IT CONNECTS TO NEURAFIKI:
After user completes assessment:
  "Found a specialist? Book an appointment"
  Links to local ANDA Directory practitioners
  Auto-filtered by profile type & location

FEATURES:
- Map view of practitioners
- Filter by: country, city, specialization, language, cost
- Verified professional badges
- User reviews and ratings
- Direct booking links
- Support group finder
- Community resources
- Feedback system

DATA STRUCTURE:
- Practitioners table (name, credentials, location, specialization, languages)
- Organizations table (NGOs, schools, advocacy groups)
- Support Groups table (online/in-person, schedule, topic)
- Ratings/Reviews table (user feedback)
- Verification logs (admin tracking)

BUDGET ESTIMATE: $40-60K (development + content curation)
TEAM: 2-3 developers, 1 content curator, 1 community manager

DATA FLOW: HOW IT ALL CONNECTS
===============================

1. USER JOURNEY:

User lands on ANDA.org
    ↓
Chooses: "Take NeuRafiki Assessment"
    ↓
Complete profile selection
    ↓
Take assessment (8-20 minutes)
    ↓
Get personalized results showing:
  - Profile score (Autism 78%, ADHD 65%, etc.)
  - Interpretation ("You may have features of...")
  - Recommended next steps
    ↓
See recommendations from ANDA ecosystem:
  ✓ "Recommended Courses" (ANDA Learning)
  ✓ "Specialists in Your Area" (ANDA Directory)
  ✓ "Join Support Groups" (ANDA Community)
  ✓ "Tools for Your Profile" (ANDA Tools)
  ✓ "Resources on Diagnosis" (ANDA Resources)
    ↓
User can:
  - Take a course
  - Book specialist appointment
  - Join community forum
  - Download toolkit
  - Read articles

2. DATA SHARING:

NeuRafiki collects:
- Assessment profiles (ADHD, Autism, Dyslexia, etc.)
- User location (country)
- User language
- Age group
- Responses to 800+ questions
- Completion time & patterns

This data feeds:
- ANDA Directory (practitioner recommendations)
- ANDA Learning (course recommendations)
- ANDA Community (group suggestions)
- ANDA Tools (toolkit recommendations)
- ANDA Advocacy (aggregate anonymized data for policy work)

3. BENEFITS TO ECOSYSTEM:

NeuRafiki → ANDA Components:
- Real data on neurodiversity prevalence
- User feedback on resources
- Geographic hotspots for support
- Language preferences
- Age-specific needs

ANDA Components → NeuRafiki:
- Practitioner expertise
- Course content
- Community stories
- Tools validation
- Policy insights
