DATA FLOW:

NeuRafiki User Assessment
     ↓
Captures:
  • Profile type (ADHD, Autism, Dyslexia, etc.)
  • Location (country, city)
  • Language preference
  • Age group
  • Assessment responses (800+ questions)
  • Time patterns & behavior
     ↓
Feeds to:
  • ANDA Learning (course recommendations)
  • ANDA Directory (specialist suggestions)
  • ANDA Community (group suggestions)
  • ANDA Tools (toolkit recommendations)
  • ANDA Advocacy (aggregate anonymized data)
     ↓
User gets:
  • Personalized recommendations
  • Local practitioner matches
  • Support communities
  • Curated tools
  • Educational resources

8. PERFORMANCE OPTIMIZATION
═════════════════════════════

CLIENT-SIDE:
  ├─ Code splitting by route
  ├─ Image optimization (WebP, responsive)
  ├─ Lazy loading of components
  ├─ CSS extraction to separate files
  ├─ JavaScript minification
  └─ Caching strategies

SERVER-SIDE:
  ├─ Database query optimization
  ├─ Connection pooling
  ├─ Caching with Redis (optional)
  ├─ API response compression
  └─ Server-side rendering where needed

METRICS TARGETS:
  ├─ LCP (Largest Contentful Paint): <2.5s
  ├─ FID (First Input Delay): <100ms
  ├─ CLS (Cumulative Layout Shift): <0.1
  ├─ Lighthouse Score: >95
  └─ TTFB (Time to First Byte): <600ms
