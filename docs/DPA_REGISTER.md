# Data processing agreements

Every vendor that handles NeuRafiki users' personal data, and the agreement that covers it. Recorded 17 October 2026. Update this file in the same PR that adds or removes a vendor (see `AGENTS.md`).

| Vendor | What it does for NeuRafiki | Agreement | Status |
|---|---|---|---|
| Supabase | Database, sign-in, file storage | [DPA](https://supabase.com/legal/customer-resources/data-processing-addendum), part of the [terms](https://supabase.com/terms) | In place (incorporated in the terms) |
| Vercel | Hosting, Vercel Analytics | [DPA](https://vercel.com/legal/dpa) | Standard DPA; not yet recorded as reviewed |
| Cloudflare | Workers AI, Turnstile | [Customer DPA](https://www.cloudflare.com/cloudflare-customer-dpa/) | Standard DPA; not yet recorded as reviewed |
| Flutterwave | Payments | [Merchant agreement](https://app.flutterwave.com/dashboard/onboarding/agreement) (accepted in the dashboard), [privacy notice](https://flutterwave.com/us/privacy-notice), [dispute privacy](https://dispute.flutterwave.com/privacy) | In place (merchant agreement) |
| Sentry | Error reports | [DPA v5.1.0](https://sentry.io/legal/dpa/5.1.0/in-app/?userCurrentVersion=5.1.0), accepted in-app | In place (v5.1.0) |
| WhoGoHost (Go54) | Email hosting (SMTP for reminders and contact messages) | None found yet | **Open:** ask WhoGoHost/Go54 for a DPA or data-processing terms |

Lovable's DPA ([page](https://lovable.dev/data-processing-agreement), [signed PDF](https://lovable.dev/documents/Lovable_DPA_17Nov2025_Signed.pdf)) covers abiolaoshunniyi.lovable.app. This app doesn't use Lovable.
