DATABASE SCHEMA (via scripts/002-assessment-features.sql)
----------------------------------------------------------
3 NEW TABLES:

assessment_drafts
- id (uuid, primary key)
- user_id (uuid, FK to auth.users)
- assessment_type (text)
- responses (jsonb) - saved answers
- current_question_index (int) - progress
- started_at (timestamp)
- last_saved_at (timestamp)
- profile_metadata (jsonb) - extra user data
- created_at, updated_at
- RLS: Users can only see their drafts
- Unique constraint: user_id + assessment_type

assessment_comparisons
- id (uuid, primary key)
- user_id (uuid, FK)
- first_assessment_id (uuid, FK to assessment_results)
- second_assessment_id (uuid, FK to assessment_results)
- notes (text) - user notes
- created_at
- RLS: Users can only see their comparisons

assessment_exports
- id (uuid, primary key)
- user_id (uuid, FK)
- assessment_id (uuid, FK to assessment_results)
- format (text) - 'pdf' or 'json'
- include_interpretation (boolean)
- shareable_link (boolean)
- expires_at (timestamp) - null if no expiration
- last_accessed_at (timestamp)
- download_count (int) - track access
- created_at
- RLS: Users can only see/manage their exports

USAGE EXAMPLES
==============

1. SAVE ASSESSMENT DRAFT
   const draft = await assessmentDraftService.saveDraft({
     userId: user.id,
     assessmentType: 'adhd',
     responses: { q1: 'yes', q2: 'sometimes' },
     currentQuestionIndex: 15,
     startedAt: new Date().toISOString(),
     lastSavedAt: new Date().toISOString()
   })

2. RESUME FROM DRAFT
   const draft = await assessmentDraftService.getDraft(
     userId,
     'adhd'
   )
   if (draft) {
     // Restore assessment state
     setResponses(draft.responses)
     setCurrentQuestion(draft.current_question_index)
   }

3. CREATE COMPARISON
   await assessmentComparisonService.createComparison({
     userId: user.id,
     firstAssessmentId: 'uuid-1',
     secondAssessmentId: 'uuid-2',
     notes: 'After therapy intervention'
   })

4. CALCULATE CHANGES
   const changes = assessmentComparisonService.calculateScoreChanges(
     { adhd: 42, anxiety: 35 },
     { adhd: 38, anxiety: 28 }
   )
   // Returns: { adhd: { before: 42, after: 38, change: -4, percentChange: -9 }, ... }

5. CREATE EXPORT
   const exportRecord = await assessmentExportService.createExport({
     userId: user.id,
     assessmentId: assessment.id,
     format: 'pdf',
     includeInterpretation: true,
     shareableLink: true,
     expiresIn: 30
   })
